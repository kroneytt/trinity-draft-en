# Trinity Draft Unite Rulebook

## About this rulebook

**Unite** combines two Trinity Draft boxes into one big draft. Today that means Blaze (TD-01) and Phantom (TD-02); the publisher plans for future expansions, such as Storm and Regalia (working titles), to join in the same way.

Unite changes only what you play with: the components, the packs and the choice of Epics. Everything else works exactly as in the Standard rulebook, with the same terms. Unite components can also be used for DUEL.

Trinity Draft, its cards, names and rules are © 2025 Mikiseishindo / AsobiDays. This is a fan translation and is not affiliated with the publisher. Where this book and the official Japanese rules disagree, the official rules are correct.

## 2. What you need

Take two different Trinity Draft boxes and use these components:

| Component | Count | Notes |

| Draft Cards | 702 | **All** from both boxes, including both sets of VOID. |
| Basic Color Cards | 64 | 4 colors, 16 of each (one box's worth). |
| Reserve Cards | 3 | |
| Wall Cards | 3 | |
| Walls | 3 | |
| Trinity Counters | 30 | |

## 3. Making the packs

Make the packs the usual way (Standard rulebook, 4.1), but from all **702** Draft Cards of both boxes together. Shuffle them face down and deal them into packs of 13.

A game still uses **9 packs**. The 702 cards make 54 packs, enough for 6 games.

## 4. Epic Cards

At the start of the Draft, deal each player all **8** different Epic Cards: the 4 from each box. Each player still uses **1**, chosen from all 8 during the Build.

## 5. Draft, Build and Battle

No change. Draft, Build and Battle exactly as in the Standard rulebook.

## 6. Sorting the boxes back

When you're done, sort the cards back into their own boxes:

- Look at the **expansion mark** in the top-left corner of each card to tell which box it belongs to.
- **VOID** cards have no expansion mark. Put 9 back in each box.
